## ADDED Requirements

### Requirement: Внутреннее звено может работать без TLS

Звено цепочки, живущее на одной машине с клиентами, SHALL допускать
слушатель без TLS на loopback-адресе. Соединение с следующим звеном при этом
SHALL оставаться `https` с обычной проверкой сертификата.

#### Scenario: Локальное звено без TLS перед внешним звеном

- **WHEN** внутреннее звено запущено с источником `none` на loopback, его
  апстрим — внешнее звено по `https`, и клиент по `http://` присылает
  запрос с верным пропуском на внутреннее звено
- **THEN** внешнее звено получает запрос по TLS с пропуском на следующее
  звено, а клиент — ответ Anthropic
