## MODIFIED Requirements

### Requirement: Без внешнего шлюза и токена подписки команда отказывает

Для апстрима OpenAI команда `local` SHALL требовать разрешение на
использование плана ChatGPT в выбранном локальном профиле. Для цепочки
Anthropic команда `local` SHALL требовать пропуск для апстрима первого
токена звена (метка по умолчанию `local`). Если для этой метки задан маршрут, требуется
его ключ из `--upstream-route-keys`. При отсутствии маршрута требуется
общий `--upstream-key`. В режиме `oauth` также требуется токен подписки
`ANTHROPIC_AUTH_TOKEN` из окружения или файла настроек. При отсутствии
любого из них команда SHALL отказать до запуска звена, назвав недостающее
и где его взять.

#### Scenario: Нет пропуска внешнего шлюза

- **WHEN** команда `local` выбирает цепочку Anthropic и запущена без `--upstream-key` и без ключа
  маршрута для метки токена звена
- **THEN** звено не поднимается, `claude` не запускается, ошибка объясняет,
  что локальное звено работает только в цепочке и требует адрес и пропуск
  внешнего шлюза

#### Scenario: Ключ маршрута вместо общего пропуска

- **WHEN** команда `local` выбирает цепочку Anthropic и запущена без `--upstream-key`, но с маршрутом и
  ключом маршрута для метки токена звена
- **THEN** звено поднимается, и запрос локального токена уходит на апстрим
  маршрута с его ключом

#### Scenario: Общий пропуск при маршруте без ключа

- **WHEN** команда `local` выбирает маршрут Anthropic без ключа этого
  маршрута, а общий `--upstream-key` задан
- **THEN** звено и `claude` не запускаются, ошибка называет метку и
  настройку ключей маршрутов

#### Scenario: Нет токена подписки

- **WHEN** выбран апстрим Anthropic в режиме `oauth`, и `ANTHROPIC_AUTH_TOKEN` нет ни в окружении, ни в
  файле настроек
- **THEN** звено не поднимается, ошибка называет переменную и подсказывает
  `claude setup-token`

#### Scenario: `claude` не найден

- **WHEN** исполняемый файл `claude` не найден в `PATH` и не задан флагом
- **THEN** звено не поднимается, ошибка называет, что искали и где

#### Scenario: OpenAI с локальным профилем ChatGPT

- **WHEN** первый токен выбирает OpenAI, а у профиля есть разрешение
  на использование плана ChatGPT
- **THEN** `local` запускает Claude Code с пропуском локального звена
  без требования `ANTHROPIC_AUTH_TOKEN` или пропуска внешнего шлюза

#### Scenario: Нет разрешения на использование плана ChatGPT

- **WHEN** первый токен выбирает OpenAI, а профиль отсутствует или
  разрешение было отозвано
- **THEN** `local` останавливается до запуска Claude Code и подсказывает,
  как пройти локальный вход

#### Scenario: OpenAI на внешнем шлюзе

- **WHEN** в локальном окружении задан пропуск внешнего маршрута OpenAI
  и включён режим `upstream-chatgpt`
- **THEN** Claude Code запускается с локальным пропуском; внешний шлюз
  получает свой маршрутный пропуск, а credential Anthropic не нужен
