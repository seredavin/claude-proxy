## Why

Пользователь хочет сохранить Claude Code как интерфейс и выполнять запросы
к моделям OpenAI по своей подписке ChatGPT. Выпуск v1.6.0 умеет выбирать
адрес по метке токена, но передаёт запросы в протоколе Anthropic.

## What Changes

- Добавить локальный вход через официальный Sign in with ChatGPT с
  сохранением и обновлением учётных данных на ноутбуке.
- Разрешить выбор OpenAI как общего апстрима и независимо для маршрутов
  по меткам. «Дополнительный» апстрим означает маршрут по метке.
- Преобразовывать Anthropic Messages и поток событий в OpenAI Responses API
  и обратно, включая вызовы локальных инструментов Claude Code.
- Разрешить `local` запускаться с выбранным профилем ChatGPT для маршрута
  OpenAI. Для выбора Anthropic или следующего шлюза действуют их условия.
- Показывать разрешённые псевдонимы OpenAI в меню `/model` Claude Code
  и применять выбранную модель в следующих запросах с тем же токеном.
- Сохранить существующие сценарии Anthropic и цепочки шлюзов.

## Capabilities

### New Capabilities

- `openai-chatgpt-upstream` — локальная авторизация, выбор провайдера и
  адаптация запросов Claude Code к OpenAI Responses API.

### Modified Capabilities

- `local-launcher` — условия запуска зависят от выбранного апстрима.
- `gateway-chaining` — требование клиентского credential применяется
  к запросам в цепочку Anthropic.

## Impact

Затрагивает `local`, конфигурацию маршрутов, слой шлюза, логи, трассу и
документацию и systemd. На ноутбуке независимые запуски выбирают модель
токеном удалённого шлюза из `local.env`.
