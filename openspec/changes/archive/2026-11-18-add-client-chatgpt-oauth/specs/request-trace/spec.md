## ADDED Requirements

### Requirement: OAuth-обмен исключён из журналов и трассы

Endpoint обновления OAuth SHALL обрабатываться без записи тела, заголовков
и ответа в трассу при любом результате. Логи SHALL содержать только
безопасную диагностику статуса. Заголовок Bearer, добавленный локальным
звеном для инференса, SHALL быть скрыт в трассе обоих звеньев.

#### Scenario: Трасса включена при успешном и отклонённом обновлении

- **WHEN** шлюз обрабатывает успешный или отклонённый OAuth refresh при
  включённой трассе
- **THEN** для обмена не создаются файлы трассы, ни старые, ни новые
  токены не появляются в журналах
