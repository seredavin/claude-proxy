## Why

При использовании OpenAI через удалённый шлюз v1.7.0 хранит профиль ChatGPT
на сервере. Пользователю нужен доступ к OpenAI с компьютера, который видит
только шлюз, при хранении OAuth-профиля на клиенте.

## What Changes

- Добавить режим OpenAI с токеном клиента для общего апстрима и маршрутов
  по меткам на удалённом шлюзе.
- Научить `local` брать токен из локального профиля, передавать его по
  HTTPS и обновлять профиль через фиксированный endpoint шлюза.
- Запретить запись OAuth-данных в журналы, трассы и файлы сервера при
  пересылке. Сохранить авторизацию по токену шлюза и список моделей маршрута.
- Описать первичный вход на другой машине и смену ранее использовавшегося
  серверного профиля после проверки.

### Modified Capabilities

- `openai-chatgpt-upstream` — клиентский OAuth и обновление через шлюз.
- `local-launcher` — выбор локального профиля при выходе через внешний шлюз.
- `request-trace` — OAuth-обмен полностью исключается из трассы.

## Impact

Изменяются настройки `local`, `run` и systemd, хранение клиентского
профиля, выбор credential у апстрима OpenAI и обработка секретов.
